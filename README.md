# AI Job Agent

AI-powered job search and recommendation agent.

## Architecture

The project collects job vacancies from multiple sources,
analyzes them against the user's profile, and sends relevant
recommendations to Telegram.

## Planned Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Ollama
- Telegram Bot API
- Docker
- Prometheus
- Grafana
- Loki
